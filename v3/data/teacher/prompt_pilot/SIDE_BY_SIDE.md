# Prompt pilot: 20 works side by side (#1322)

Each work shows the record, then each prompt's keywords in its own order. ~~Struck~~ = the Opus judge rejected it (strict rubric: supported by the record, about the work, not its document type). Flags: *(doc-type)*, *(country, no evidence)* = what the vocabulary rules would purge. Prompts: **current** = the God-label prompt (3–8 keywords, sees Type / Language / Year); **minimal** = "Assign keywords that describe what this work is about."; **+ aboutness** adds "Describe its subject matter: not the kind of document it is, and not a country or place unless the work is about that place. Write the keywords in English."; **lean input** = the same prompt shown only title, abstract and venue; **may abstain** adds "If the record says nothing about its subject, return an empty list."; **minimal, English, lean input, may abstain** = the last one without the aboutness sentence (Jason's question: are the prohibitions still needed?)
